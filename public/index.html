01 — About

Building systems where correctness matters

I’m Hammed, a software engineer in London with years of experience in fintech, building well-known products used by millions of people and automating workflows with AI. I’ve built credit card systems, a credit monitoring product that people use to keep an eye on their credit health, infrastructure for deploying web applications, and CRM tools. I’ve done this in both large organisations and startups.

I build high-performance software end to end and I’m very proficient with AI tools. What I enjoy most is working out what actually needs to be built, getting the right people aligned on it, and owning it until it works in production.

I’m calm when things go wrong, and I write things down. I care about clear API contracts, honest status updates and design docs other people can pick up without me. I’ve led small teams by setting direction and unblocking people, not by handing out tickets.

Outside work, I hack on open-source projects. sarabi is a deployment tool that hosts this site, and registry-auth, a token authentication server for Docker registries, is used in production by Apptainer. I also practise data structures and algorithms in my spare time to keep my fundamentals sharp.

03 — Open source

Things I've built in the open

Featured project

sarabi

A simple, full-stack application deployment tool for lazy devs — and the thing that hosts this website.

  • Deploy any app that has a Dockerfile, backend and static frontend together, in a single step.
  • Unlimited environments (dev, prod, pr-123…), each with its own URL, database and config.
  • Provisions PostgreSQL, MySQL, MongoDB and Redis — locked down from the internet by default, with automatic backups to S3-compatible storage.
  • Automatic HTTPS via Caddy, log retention, horizontal replicas and one-command rollbacks.
