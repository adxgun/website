Featured project

sarabi

A simple, full-stack application deployment tool for lazy devs — and the thing that hosts this website.

  • Deploy any app that has a Dockerfile, backend and static frontend together, in a single step.
  • Unlimited environments (dev, prod, pr-123…), each with its own URL, database and config.
  • Provisions PostgreSQL, MySQL, MongoDB and Redis — locked down from the internet by default, with automatic backups to S3-compatible storage.
  • Automatic HTTPS via Caddy, log retention, horizontal replicas and one-command rollbacks.
